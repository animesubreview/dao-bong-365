# Ảnh nhân vật cho mục "Bạn đang quan tâm gì?"

Thả file PNG (đã tách nền trong suốt) vào đúng thư mục này, đặt tên như sau:

- dragon-ball.png
- bleach.png
- one-piece.png
- conan.png
- pokemon.png
- doraemon.png
- demon-slayer.png

Card ở trang chủ sẽ tự động hiển thị đúng ảnh nhân vật đứng lệch phải,
không cần sửa code gì thêm. Nếu file chưa tồn tại, card sẽ tạm hiện
poster phim lấy từ API thay thế.
